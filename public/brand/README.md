# Marken-Assets Dritter

Hier gehört **`claude-logo.svg`** hinein — das offizielle Asset aus Anthropics
Brand-Assets (https://brandfolder.com/anthropic/), unverändert.

Solange die Datei fehlt, rendert `ClaudeBadge.astro` nur den Text
„Works with Claude". Das ist korrekt, nur ohne Bildmarke.

**Nie ein nachgebautes oder aus einer Sammelseite gezogenes Logo ablegen.**
Falsch nachgebaut ist schlechter als gar nicht.

Regeln aus Anthropics Guidelines, die der Badge einhält:
- Logo nur uniform skalieren, nie verzerren, strecken oder rotieren
- Auf heller, off-weißer oder neutraler Fläche platzieren (der Badge ist genau das)
- Freiraum rundherum etwa in Höhe des Logos
- Keine Aussage, die Partnerschaft, Sponsoring oder Endorsement nahelegt
